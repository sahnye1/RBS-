## 驱动与诊断口径

**PWM（`valve_pwm.c`）**

- 100kHz，1 步 = 10μs；period 1000~50000 步（10~500ms），硬上限 65535 步 = 655.35ms
- `PWM_CC0_OFFSET = 0` —— **禁止改回非 0**（非 0 时"恒高"驱动不成立，周期起点丢高电平 → 排气阀保压泄漏）
- 极性：**进气阀后段高**（CC0 = period − htime）；**排气阀 / ASR 阀前段高**（CC0 = 0）
- 接口：`ValvePwm_SetDuty`（检阀，归零重开）/ `SetDutyNoReset`（控阀，周期边界衔接）/
  `SetDutyLive`（运行中改参，相位连续）/ `SetOnOff`（恒开·恒关）；`Bts724g_SetValve()` 自动分发

**诊断（`bts724g.c`）**

- `ValveDiag_Process()` 每 10ms 一步、40ms 换一步，4 步轮转：阀开路 → 阀短路 → 芯片开路 → 芯片短路
- 极性：阀开路 = ST Low；阀短路 = FAR High；芯片开路 = 全 IN=HIGH 后两路 ST 均 Low
- 消抖：阀级 3 次 / 芯片级 5 次；某芯片已有 ≥2 阀开路时跳过芯片级检测（防误报）
- ⚠ 全部检测依赖阀线圈已连接 —— **裸板（未接线圈）读数不可信**

**低边开关（`gpio.h`，与阀线圈回路串联）**

| 引脚 | 功能 | 说明 |
|------|------|------|
| **P2.0** | 前桥 ASR 低边（`ASRFLowSideSw` / FarFA_in） | 22口进气阀 / TR_ASR / 21口 / RXI~LXI **共用同一低边** |
| **P6.2** | 后桥 ASR 低边（`ASRRLowSideSw` / FarDA_in） | 22口排气阀低边 |

- RTE 接口：`InLowSideSwX4_16()` → P2.0、`OutLowSideSwX2_16()` → P6.2（本层带幂等保持缓存）
- ⚠ 与阀诊断**共享同一低边**，由 `Gpio_ASRxLowSideEnable()` 引用计数管理 → **不要直接写该 GPIO**
